Extra Dangerous Exec Commands

Additional commands declared via AGENTICGO_EXTRA_EXEC_COMMANDS and baked into the deployment image. They are not runnable until enabled per agent on Agents → Extra Dangerous Exec Commands.
⚠ DANGEROUS — Custom commands
These commands run with the full privileges of the agenticgo process and can cause real harm. For example kubectl can delete cluster resources and git can rewrite history. Only declare commands you have deliberately installed, and enable them per agent only if you understand the risk.
